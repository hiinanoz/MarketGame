# Çeviri (i18n)

Diller: **tr** (kaynak), en, de, es, fr, it, ko, ja. Dal: `i18n` (bitince main'e).

## Nasıl çalışır

- `src/i18n.js`: `t('Türkçe metin', { ad: değer })` seçili dildeki karşılığı döndürür. Anahtar Türkçe metnin kendisi.
  Yer tutucu `{ad}`; çoğul gereken yerde dil dosyasındaki değer `{ "one": "…", "other": "…" }` (sayı `n` parametresi).
  Eksik çeviri → İngilizce → Türkçe.
- Dil modül yüklenirken seçilir: ayar `options.lang` (`auto` = cihaz dili, yoksa İngilizce). Ayarlarda "Dil · Language";
  değişince oyun kaydedilip sayfa yenilenir. `config.js` gibi modüllerin sabit metinleri bu yüzden doğrudan `t()` ile yazılabilir.
- `index.html`'deki sabit metinler açılışta `translateDom()` ile çevrilir (metin düğümü, `title`/`aria-label`/`placeholder`).
  İçinde `<b>` gibi biçim olan paragraf `data-tx` ile işaretlenir, innerHTML tek parça çevrilir.
- Sayı ve tarih: `num(n)` / `dateTime(d)` (`toLocaleString('tr-TR')` yerine).
- iOS: `apple/ios/App/App/<dil>.lproj/InfoPlist.strings` + `Info.plist → CFBundleLocalizations`. Cihaz dili WKWebView'e
  ancak dil burada listeliyse geçer.

## Kurallar (metin taşırken)

1. Metni `t()` ile sar; değişkenleri şablona gömme: `` `Gün ${n}` `` → `t('Gün {n}', { n })`. `t()` içinde `${}` olmaz
   (denetim aracı uyarır).
2. Türkçe ekleri değişkene yapıştırma (`${ad}'ın`): cümleyi yer tutucuyla kur, ek gerekiyorsa cümleyi değiştir.
3. Cümleyi parçalara bölme (`t('Toplam') + ' ' + t('kasa')`): her dilde söz dizimi farklı; tam cümleyi çevir.
4. Dosyada `t` adlı yerel değişken varsa yeniden adlandır (ör. `const t = …` → `tt`), yoksa `t()` gölgelenir.
5. Emoji ve `$` tutarı metnin içinde kalabilir; çevirmen korur.
6. Oyuncunun verdiği adlar (market, işletme) çevrilmez.

## Araçlar

```bash
node tools/i18n-check.mjs        # her dil: çevrilen / eksik / kullanılmayan
node tools/i18n-check.mjs en     # İngilizcede eksik anahtarlar (JSON)
python3 tools/i18n-add.py yeni.json   # { "Türkçe": ["en","de","es","fr","it","ko","ja"] } → src/locales/*.json
node tools/i18n-scan.mjs src/x.js   # dosyada henüz t() ile sarılmamış metinler
npx eslint --no-config-lookup -c tools/i18n-eslint.config.mjs src/*.js   # t gölgeleme / tanımsız değişken
```
